# David: Shepherd of Israel

Bible-inspired side-scrolling action platformer featuring David, his sling, seven stages, and Goliath as the final boss.

## Prototype

The v0.2 playable prototype is being migrated into this repository. Planned first vertical slice: authored platforming terrain, charged sling attacks, collectible stone ammunition, wolves, and a multi-phase Alpha Wolf boss.

## Design goals

- Responsive movement and double jump
- Sling charge and stone upgrades
- Seven narrative levels culminating in David versus Goliath
- Keyboard and mobile-first touch controls
- Original artwork, music and code (inspired by NES-era action games, not copied)

## Development

Initial scaffold; game source and build verification pending. Do not treat this repository as a playable release yet.
